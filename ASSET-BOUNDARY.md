# Asset boundary

This repository and its source ZIP contain project-authored source and documentation only. They do not contain Fab, Poly Haven, fal.ai or Tripo media. No new asset generation or purchase occurred during source-kit implementation.

The existing project retains the approved Widowfen references, Blackbell Tripo output and twelve CC0 Poly Haven sources. Its ASSET-LEDGER.md is the acquisition record. Greystone and Minions are installed, indexed and bound in the isolated Windows character project, and the first character package passed its runtime checks. Exact marketplace revision and accepted-license receipt export remain unverified. Keep those sources in the user's Unreal project and preserve their original terms/receipts. Do not upload them as model input.

This document is an inventory boundary, not a new license grant or an assertion that third-party rights have been independently cleared for submission.

They use oscillators and seeded noise; no sampled recordings, external audio files or model/media API are involved. The environment dressing reuses the already-installed Poly Haven meshes.
